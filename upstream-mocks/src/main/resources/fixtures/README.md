# Fixtures

- `products.json`, `spec-labels.json` — 15 real Kramp products. Item numbers, brands, EANs, sales units,
  localized names, category names, image URLs and shop URLs are copied from kramp.com (October 2026).
  Descriptions and spec labels were written/translated for this demo.
- `prices.json`, `discounts.json`, `customers.json`, `stock.json` — **fictitious**. Kramp prices are
  behind a login; stock levels and customers are invented. Warehouse locations are real.
